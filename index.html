🎯 The Master DSA Pattern Finding Framework (How to Identify Any Problem)
Follow the 3-step senior engineer interview formula: 1. Classify by Keywords & Signals ➔ 2. Bound by Input Constraint N ➔ 3. Formulate Brute Force then Eliminate Bottleneck
Interview Formula
💡
How to Attack Any DSA Question in an Interview:
Step 1: State the Brute Force First — Never stay silent or jump straight to complex code. Clearly articulate: "A naive brute-force approach would check every pair/permutation in O(N²) time by running nested loops. The bottleneck here is that we re-scan elements we've already compared." This proves algorithmic awareness and establishes a working baseline.
Step 2: Inspect Input Constraints (N) — The maximum value of N immediately reveals the required Big-O time complexity (see Table below). If N = 10⁵, an O(N²) solution will exceed the 1-second limit (~10⁸ ops); you MUST find an O(N log N) or O(N) approach.
Step 3: Extract Trigger Keywords — "Contiguous subarray" ➔ Sliding Window; "Next greater" ➔ Monotonic Stack; "Sorted array pair" ➔ Two Pointers; "Minimize maximum" ➔ Binary Search on Answer; "Prerequisites" ➔ Topological Sort.
